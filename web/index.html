🔐 How your keys and data are handled

  • API keys are stored in the app's private storage on your phone — never uploaded, never in a web page.
  • Every order is signed with HMAC-SHA256 on the device by the Kotlin layer.
  • Create keys with trading enabled and **withdrawal disabled**. The app never asks for withdrawal rights.
  • Signals, charts and paper trading need no account and no key at all.

⚠️ Read this first

FAQ

Questions and answers

Do I need an account or API key?

No. Prices, charts, the signal engine, alerts and paper trading work with no account and no key. Keys are only needed if you want to place real orders on Binance or Bybit.

Is it really free?

Yes — free and open source (this repo). There is no subscription and no paid indicator tier. Optional AI explanations use your own provider key if you choose to add one; without a key the built-in explanation is used.

Does it work offline?

The app opens offline and shows clearly-labelled simulated demo data, so you can explore every screen. Real prices need internet.

Which exchanges are supported?

Public market data from Binance, Bybit and OKX (switchable in settings, with automatic fallback). Live trading is supported on Binance and Bybit spot. Binance testnet is supported too.

How safe is the bot?

It enforces a maximum number of open positions, a per-symbol cooldown and a daily-loss stop that halts trading by itself, and it runs in a foreground service with a visible notification. Still: test in paper mode first, and only risk what you can afford to lose.

Where is the source?

Everything is in the Rs-et repository: the Android shell, the Kotlin signing bridge, the web/JS terminal (ta.js + app.js) and the CI that builds the APK.
